## Español

### Información General

**IkaTensión** es una aplicación web diseñada como un método sencillo para que los usuarios guarden y hagan seguimiento de sus registros de tensión arterial.

**Propósito:** Ofrecer una herramienta simple y directa, sin complicaciones, para llevar un control personal de la tensión arterial.

**Público Objetivo:** Principalmente personas con hipertensión o cualquier individuo que desee monitorear su tensión arterial de forma regular.

### Características Principales

* **Registro de Tensión:** Permite ingresar fácilmente las lecturas de tensión arterial (sistólica/diastólica).
* **Timestamp Automático:** Guarda automáticamente la fecha y hora exactas cada vez que se registra una nueva lectura.
* **Exportación a CSV:** Ofrece la funcionalidad de exportar todos los registros guardados a un archivo en formato CSV para análisis o respaldo.
* **Simplicidad y Accesibilidad:** Se destaca por ser una aplicación web muy simple y enfocada, que no requiere instalación previa. El acceso es directo a través del navegador.

## English

### General Information

**IkaTensión** is a web application designed as a simple method for users to save and track their blood pressure records.

**Purpose:** To provide a simple, straightforward tool, without complications, for personal blood pressure monitoring.

**Target Audience:** Primarily individuals with hypertension or anyone wishing to regularly monitor their blood pressure.

### Key Features

* **Blood Pressure Logging:** Allows easy input of blood pressure readings (systolic/diastolic).
* **Automatic Timestamp:** Automatically saves the exact date and time whenever a new reading is recorded.
* **CSV Export:** Offers functionality to export all saved records into a CSV format file for analysis or backup.
* **Simplicity and Accessibility:** Stands out for being a very simple and focused web application that requires no prior installation. Access is direct via the browser.
